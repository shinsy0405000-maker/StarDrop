# 별똥 택배 (StarDrop)

행성의 중력을 이용해 소포를 배달지까지 휘돌려 보내는 우주 배달 퍼즐 게임입니다.
외부 게임 엔진이나 라이브러리 없이 **순수 자바(Swing)** 로 물리, 그래픽, 효과음을 모두 직접 구현했습니다.

자바 프로젝트 수행평가 작품입니다.

## 실행 방법

JDK 21 이상이 필요합니다.

```
javac -encoding UTF-8 src/StarDrop.java -d out
java -cp out StarDrop
```

IntelliJ IDEA에서는 이 폴더를 열고 `src/StarDrop.java`의 `main`을 실행하면 됩니다.
실행 구성의 JDK가 프로젝트 SDK와 같은지 확인하세요. 버전이 다르면 `UnsupportedClassVersionError`가 납니다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 조준 (출발점에서 멀수록 세게) |
| 클릭 | 발사 |
| 비행 중 누르고 있기 / Space | 진행 방향으로 추진 (연료 1.2초) |
| 방향키 | 각도와 세기 조정. 톡 누르면 한 칸, 누르고 있으면 점점 빠르게. 여러 키 동시에 가능 (Shift로 더 세밀하게) |
| R | 다시 조준 |
| H | 정답 방향 보기 |
| M | 소리 켜기/끄기 |
| F3 | FPS 표시 |
| Esc | 처음 화면 |

화면 오른쪽 위의 버튼(다시 조준, 정답 방향 보기, 소리, 구역 목록)으로도 같은 일을 할 수 있습니다.

## 게임 구성

- **5개 구역**: 구역마다 새 천체가 하나씩 등장합니다. 다 끝내면 무한 배달이 이어집니다.
- **천체**: 행성(표면 5종, 고리), 공전하는 달, 블랙홀, 밀어내는 별, 웜홀
- **별 3개**: 자동 풀이기가 찾은 정답 궤도 위에 놓이므로, 별 3개를 모두 얻는 길이 반드시 있습니다.
- **기록 저장**: 구역마다 얻은 별 수가 저장되어, 구역 목록에서 볼 수 있습니다.
- **소리**: 배경음, 추진음, 효과음을 음원 파일 없이 코드로 직접 계산해 만듭니다.

## 핵심 원리

**중력 계산** (`GravityBody.pull`): 만유인력 공식에 따라 가속도 = 질량 / 거리² 를 천체 방향으로 더합니다.

**운동 갱신** (`Ship.step`): 0.01초마다 가속도 → 속도 → 위치 순으로 갱신합니다.

**자동 풀이기** (`Solver.solve`): 각도 720개(0.5도 간격) × 세기 12단계를 모두 시뮬레이션하는 완전 탐색입니다.
도착한 궤도 중 각도와 세기가 조금 어긋나도 성공하는 것만 정답으로 채택해, 사람이 실제로 맞힐 수 있는 구역만 만듭니다.

## 객체 지향 설계

| 개념 | 적용 |
|---|---|
| 캡슐화 | 모든 필드는 `private`, getter로만 읽기. 반지름이 0 이하이면 생성자에서 예외 |
| 인터페이스 | `CelestialBody`: 행성, 블랙홀, 밀어내는 별, 달이 구현. 물리 계산은 종류를 모른 채 `pull()`만 호출 |
| 인터페이스 | `Drawable`: 화면에 그릴 대상을 반복문 하나로 그림 |
| 상속 | `GravityBody`(추상 클래스) ← `Planet`, `BlackHole`, `Repulsor` |
| 상속 | `Widget`(추상 클래스) ← `Button`, `LevelTile`: 화면 위의 클릭할 수 있는 요소 |
| 상속 | `MouseAdapter`, `KeyAdapter`를 상속해 필요한 메서드만 재정의 |

## 개발 로그

### 2026-11-20 — 방향키 동시 입력
- 방향키를 여러 개 동시에 누를 수 있게 함 (예: 왼쪽+위로 각도와 세기를 함께 조정). 전에는 운영체제 키 반복에 맡겨서 마지막에 누른 키만 움직였음
- 톡 누르면 한 칸만, 0.25초 넘게 누르고 있으면 계속 움직이고 1초에 걸쳐 3배까지 빨라짐. Shift를 같이 누르면 세밀하게
- 창이 포커스를 잃으면 눌린 키를 모두 뗀 것으로 처리 (키가 눌린 채로 남는 문제 방지)
- 버그 수정: 처음 화면의 시범 구역을 만드는 중에 "배달 시작"을 빨리 누르면, 늦게 끝난 시범 구역이 게임 구역을 덮어써서 시범 화면으로 돌아가던 문제

### 2026-11-20 — 웹 버전과 똑같이 맞추기
- 화면 위 UI를 웹과 같은 크기로 다시 그림. 전에는 HUD 글자가 창 크기에 따라 같이 커지고 작아졌는데, 이제 웹처럼 화면 픽셀 기준으로 고정
- 오른쪽 위 클릭 버튼 추가: 다시 조준, 정답 방향 보기(켜지면 민트색), 소리 끄기/켜기, 구역 목록
- 구역 목록 화면 추가: 구역별 별 기록, 잠긴 구역, 모은 별 합계. 기록은 컴퓨터에 저장되어 다음 실행에도 남음
- 처음 화면을 웹과 같게: 도장, 빛 번지는 제목, 설명, 버튼 3개(배달 시작, 구역 목록, 무한 배달), 키 안내
- 구역 첫 화면에 안내 문구 추가 (첫 발사 때 사라짐)
- 배달 완료 영수증에 버튼 3개(다음 구역, 다시 배달, 구역 목록), 도착 후 0.9초 불꽃을 보여 준 뒤 영수증 표시
- 배경음(7개 음의 잔잔한 화음), 추진할 때 나는 소리, 효과음 메아리 추가. 소리 전체를 오디오 스레드 하나에서 섞어 지연을 줄임
- 배경을 창 전체에 채움 (창 비율이 달라도 검은 띠가 생기지 않음)
- 직전 실패 자취를 점선으로, 혜성 꼬리를 두 겹(주황 + 흰색)으로 웹과 같게 변경
- 조준 예측 계산을 마우스 움직일 때마다가 아니라 한 프레임에 한 번만 하도록 변경

### 2026-11-17 — 자바 완전판
- 쉬운 버전(행성만 있는 5구역)을 웹 버전 수준으로 확장: 달, 블랙홀, 밀어내는 별, 웜홀, 추진, 효과음, 무한 배달
- 계획서의 객체 지향 설계 적용: `CelestialBody`, `Drawable` 인터페이스, `GravityBody` 추상 클래스, 캡슐화
- Swing 타이머 대신 모니터 주사율에 맞춘 게임 루프로 바꿔 움직임이 끊기지 않게 함
- 행성과 배경을 창 크기에 맞춰 한 번만 그려 두고 재사용해 그리기 속도 개선

### 2026-11-16 — 첫 버전
- 웹 버전(`web/index.html`) 완성: 16개 구역, 자동 풀이기, 절차적 행성 그래픽, Web Audio 소리
- 순수 자바 쉬운 버전 작성 (행성만 있는 5개 구역)
